# ⚡ Campus Pulse — Event Discovery & Student Community Platform

> **Created by Kankshi Komre & Surya Teja**  
> 🌐 **Live Application**: [https://suryateja4104-stark.github.io/](https://suryateja4104-stark.github.io/)

Campus Pulse is a modern, high-performance web platform built for university students to discover, track, and manage campus events, club activities, competitions, and workshop registrations.

---

## ✨ Key Features

- **📱 Dual Responsive Engine**:
  - **Desktop Mode**: Full-screen desktop dashboard with left glass navigation sidebar, header search bar, central event feed, and right activity drawer.
  - **Mobile App View**: Edge-to-edge full-bleed native mobile layout tailored for iOS Safari and Android Chrome with floating navigation taskbar.

- **🎉 Event Discovery & Filtering**:
  - Filter events by category (Design, Hackathons/Competitions, Tech Workshops, Cultural, Sports).
  - One-tap event registration, bookmarking, and custom calendar reminders.

- **🏛️ Club Directory & Activity**:
  - Explore campus student organizations (Consulting Club, TechSoc, Design Guild, etc.).
  - Follow clubs and track real-time announcements.

- **📊 CSV / JSON Data Import**:
  - Import custom event datasets for event organizers.

- **⚡ High Performance & Reliability**:
  - Built with Vite, React 19, TypeScript, and TailwindCSS.
  - Automated deployment pipeline via GitHub Pages.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 19, TypeScript, Vite
- **Styling & UI**: Tailwind CSS v4, Lucide React Icons
- **Routing**: React Router DOM (HashRouter for GitHub Pages)
- **Deployment**: GitHub Pages (`docs/` publishing directory)

---

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/suryateja4104-stark/Campus-Pulse.git
   cd Campus-Pulse
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
